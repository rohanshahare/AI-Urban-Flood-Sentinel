# Recording Checklist: AI Urban Flood Sentinel

## Pre-Recording Setup
- [ ] Ollama server is running (ollama serve).
- [ ] Model gemma3:12b is pulled and ready.
- [ ] Backend started: uvicorn backend.main:app --host 127.0.0.1 --port 8000.
- [ ] Dashboard opened at http://127.0.0.1:8000 and header shows Backend connected.
- [ ] Model warmed up: One analysis of Blocked drain performed to avoid first-run lag.
- [ ] Browser window set to 1920x1080; zoom level 100%.
- [ ] Unnecessary tabs, bookmarks, and system notifications disabled.
- [ ] Internet connection active (required for Leaflet map tiles).

## Audio Setup
- [ ] External microphone connected and levels tested (no clipping).
- [ ] Recording environment is quiet (fans off, doors closed).
- [ ] Narration recorded as a separate high-quality WAV/MP3 file.

## Post-Production
- [ ] Audio noise reduction applied.
- [ ] Narration synchronized with visual shots.
- [ ] Subtle background music added (ducked under speech).
- [ ] Captions (SRT) embedded or uploaded.
- [ ] Final export: 1080p, H.264, 30fps, exactly 150 seconds.
